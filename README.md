# 🎲 Projeto Fichas RPG

Um site para criação e gerenciamento de fichas de personagens de RPG.

---

## 🚀 Funcionalidades

* Criar personagem
* Salvar dados no navegador
* Interface simples e intuitiva

---

## 🛠️ Tecnologias usadas

* HTML
* CSS
* JavaScript

---

## 📂 Estrutura do projeto

```
projetofichas-rpg/
│
├── assets/
│   └── css/
│       └── style.css
│
├── js/
│   ├── main.js
│   ├── ficha.js
│   └── storage.js(Armazenamento local do pc(TEMPORARIO!!))
│
├── index.html
├── ficha.html
└── README.md
```

---

## ▶️ Como rodar o projeto

1. Baixe ou clone o repositório:

```
https://github.com/rangelrangel7/projetofichas-rpg.git
```

2. Abra a pasta do projeto

3. Execute o arquivo:

```
index.html
```
